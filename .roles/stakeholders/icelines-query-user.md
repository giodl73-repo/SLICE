# ICELINES Query User

## Primary concerns

- ICELINES should keep its domain-friendly query commands.
- SLICE can provide low-level expression pieces without replacing hockey UX.
- The grammar should be learnable for users who already know CLI filters.
- Domain aliases and metrics belong in ICELINES, not `slice-core`.
