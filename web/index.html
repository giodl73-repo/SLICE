A selector kernel, not a database
This playground uses the same product-neutral slice-core parser and evaluator as the native tools. It preserves record order. It does not fetch data, execute SQL, rank results or apply a consumer's business rules.


Input limits and recovery
Records: 1 MiB, 2,000 objects, 24 JSON levels and 50,000 nodes. Selector: 2 KiB, 16 nesting levels, 128 words and 16 unquoted not tokens. Catalog: 16 KiB, 128 fields with paths up to 128 bytes. The serialized request is limited to 3 MiB. These are browser admission limits, not changes to the native language.
