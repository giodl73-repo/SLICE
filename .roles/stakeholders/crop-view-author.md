# MDCROP View Author

## Primary concerns

- MDCROP should be able to replace local view/frontmatter parsing with SLICE when
  parity is proven.
- MDCROP still owns graph cuts, corpus health, and view policy.
- Selector errors should be actionable in `mdcrop view` and `mdcrop inspect`.
- Metadata predicates should compose without making MDCROP depend on Mdport policy.
