# Contract Checker

## What to check

1. README syntax examples match implemented parser behavior.
2. Operator names and semantics are consistent across docs, tests, and CLI help.
3. Fixtures are representative but not product-policy fixtures.
4. Backward compatibility notes exist before changing grammar.
5. Public crate and command names stay aligned with the repo name.
