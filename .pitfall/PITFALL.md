# SLICE PITFALL index

SLICE uses PITFALL as a compact index over selector-kernel doctrine: protected
grammar and report contracts, consumer-owned schemas and policy, diagnostics,
fold planning, and downstream rehearsal. The index cites existing specs, role
reviews, compatibility policy, consumer migration docs, tests, and validation
commands without moving local sources of truth.

## Integration

- ROLES: `.roles/ROLE.md` routes expression kernel, adapter boundary,
  diagnostics, performance, scope, contract, validation, and stakeholder
  concerns to matching reviewers.
- VTRACE: SLICE does not yet carry repo-local VTRACE docs; PITFALL cites specs,
  role reviews, compatibility policy, migration plans, wave closeouts, and
  tests until a trace layer exists.
- Tests: package tests, mock client, CLI smokes, FLETCH downstream rehearsal,
  strict formatting, and PITFALL validators are the executable evidence hooks.
